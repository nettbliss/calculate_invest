# 💰 Инвестиционный калькулятор

Адаптивный веб-калькулятор для расчёта доходности инвестиций с учётом первоначального взноса, регулярных пополнений и процентной ставки.

## ✨ Функциональность

- 💵 Расчёт будущей стоимости инвестиций
- 📈 Учёт ежемесячных пополнений
- 🧮 Простая и сложная процентные ставки
- ⚡ Мгновенный пересчёт при изменении параметров
- 📱 Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- 🔗 Доступ по прямой ссылке

## 🛠️ Технологии

- HTML5
- SCSS / CSS3
- JavaScript (нативный)
- GitHub Pages

## 🚀 Демо

[Открыть калькулятор](https://nettbliss.github.io/calculate_invest/)

## 📖 Как использовать

1. Введи **первоначальную сумму** инвестиций
2. Укажи **ежемесячное пополнение** (если есть)
3. Выбери **процентную ставку** и **срок**
4. Калькулятор автоматически покажет результат
